# MHFA Connect - Mental Health First Aid Application

## 1. Project Overview

MHFA Connect is an anonymous, multi-regional frontend web application designed for students and community members across Lesotho, Kenya, and South Africa. It provides instant access to 24/7 AI-powered support, peer counselor connections, downloadable self-help modules, and localized emergency hotlines.

## 2. Tech Stack

* **Framework**: React 18
* **Build Tool**: Vite
* **Language**: JavaScript (ES6+)
* **Styling**: CSS3 (Responsive Design, Flexbox, Custom Variables)
* **State Management**: React Hooks (`useState`, `useEffect`, `useRef`) & `sessionStorage`
* **Database & Realtime**: Supabase JS SDK
* **AI Integration**: `@google/genai` (Gemini 2.5 Flash)

## 3. Setup

Requires Node.js v18+. Execute the following commands in your terminal:

```bash
# Clone the repository
git clone [https://github.com/your-username/mhfa-connect-app.git](https://github.com/your-username/mhfa-connect-app.git)

# Navigate into the project directory
cd mhfa-connect-app

# Install dependencies
npm install

# Create local environment configuration
cp .env.example .env

# Start the local development server
npm run dev
```
